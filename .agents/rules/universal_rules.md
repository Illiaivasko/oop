# Universal Project Rules for Antigravity

- Always read `AGENTS.md`, `GEMINI.md`, and `.work/session_state.md` (top block) first.
- Maintain live progress: update `.work/session_state.md` after every meaningful step.
- Unit records: record reasoning, dead ends, and acceptance status in `.work/tickets/<TASK>.md`.
- Proactive self-evolution: when you establish a reusable pattern or receive user guidance, create/update a skill in `.agents/skills/<name>/SKILL.md`.
- Run project tests (`echo 'Run lab executable'`) and linter (`echo 'No linter configured yet'`) before declaring work complete.
- Keep commits clean, conventional, and free of debug debris.
